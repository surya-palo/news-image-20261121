A newspaper-style poster that sums up the world news of Saturday 21 November 2026 in one image: Russia's overnight missile and drone barrage on Ukraine with missiles landing in Poland, the AI stock sell-off that pushed the S&P 500 into correction, the UK–EU deals, the Shenzhen summit fallout, the COP31 deadlock, Houthi missiles aimed at Riyadh, and the magnitude 6.9 earthquake in Peru's Andes. Rendered with real text (Python + Pillow, build-time only); the entry program itself is stdlib-only and copies the image to the output.

## Run it

```sh
python3 render.py && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
